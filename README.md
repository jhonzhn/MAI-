# Un jardín para ti

Página estática adaptable a móvil y escritorio, creada con HTML, CSS y JavaScript.

Para ver: abre `index.html`. Para música, añade un archivo MP3 llamado `music.mp3` y activa el botón.

Para publicarla: crea un repositorio de GitHub, sube los archivos a `main`, y desde **Settings → Pages** selecciona **Deploy from a branch**, rama `main`, carpeta `/(root)`. GitHub mostrará el enlace publicado en esa misma sección.
